# Student CRM · Stage 1

Учебный проект на React, Express и MySQL. Сервер обслуживает вход, курсы, группы, приглашения, зачисления, расписание, посещаемость и учебные материалы. Используйте вымышленные данные.

## Запуск из PyCharm с облачной MySQL

Нужен Node.js 22 или новее. Создайте отдельную учебную базу MySQL у облачного провайдера. Docker на ноутбуке для этого способа не нужен.

Если `.env` отсутствует, выполните из корня проекта `node scripts/setup.mjs`. Укажите параметры из панели MySQL:

| Параметр | Значение |
| --- | --- |
| `DB_HOST` | DNS-имя сервера |
| `DB_PORT` | Порт из панели провайдера |
| `DB_NAME` | Имя отдельной учебной базы |
| `DB_USER` | Пользователь MySQL с правами на учебную базу и её таблицы |
| `DB_PASSWORD` | Пароль пользователя MySQL |
| `DB_TLS` | `true` |
| `DB_TLS_CA_FILE` | Абсолютный путь к CA-сертификату PEM, если его выдаёт провайдер |

Оставьте `APP_ENV=demo`, `LOCAL_INVITES=true` и сгенерированное значение `DEMO_PASSWORD`. Если провайдер требует список разрешённых IP, добавьте публичный адрес ноутбука.

Из корня проекта:

```powershell
cd client
npm ci
npm run build
cd ../server
npm ci
node --env-file=../.env scripts/migrate.js
node --env-file=../.env scripts/seed.js
cd ..
node --env-file=.env server/src/index.js
```

Для повседневного запуска достаточно последней команды либо конфигурации **Student CRM** в PyCharm. Откройте `http://localhost:8080` и войдите как `admin@crm.example` с паролем `DEMO_PASSWORD` из `.env`. Повторный seed сохраняет существующие пароли.

## Запуск с Docker

`Dockerfile` и `compose.yaml` позволяют запустить отдельную среду с MySQL в контейнере. Для неё используйте отдельный файл конфигурации с локальными параметрами из `.env.example`, заполните пароли через `node scripts/setup.mjs` в чистой папке проекта и выполните `docker compose up --build -d`, затем `docker compose exec app npm run seed`.

## Проверки и объём этапа

Интеграционные тесты требуют отдельной пустой MySQL-базы с именем, оканчивающимся на `_test`. С параметрами этой базы в окружении выполните `node --env-file=../.env --test test/integration.test.js` из папки `server`.

В учебной версии приглашения выдаются одноразовым кодом в интерфейсе. Посещаемость открывается из расписания администратором или преподавателем занятия.

PDF учебных материалов хранятся в закрытой папке `.private-files` в корне проекта или в каталоге, заданном `PRIVATE_FILE_DIR`. Скачивание идёт через CRM с проверкой прав к материалу. Для сохранения материалов при переносе проекта копируйте и базу, и эту папку. В контейнерном запуске для PDF используется отдельный том.

Задания, финансы, полный комплект отчётов и приёмочные проверки ещё предстоит завершить.
