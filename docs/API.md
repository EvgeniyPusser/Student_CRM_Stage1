# API первого этапа

Префикс: /api/v1. JSON. Публичный вход отсутствует: аккаунт создаёт администратор или начальная локальная процедура.

| Метод и путь | Доступ | Результат |
| --- | --- | --- |
| GET /health | Без входа | Доступность API и MySQL |
| GET /auth/csrf | Без входа | Создание/чтение CSRF сеанса; csrfToken в JSON |
| POST /auth/login | CSRF, Origin, лимиты | Проверка email/password; новая HttpOnly cookie, профиль и csrfToken |
| POST /auth/accept-invitation | CSRF, Origin | Одноразовый token и новый password, активация аккаунта |
| GET /auth/me | Вход | Собственный профиль, роли, today и timeZone |
| POST /auth/logout | Вход + CSRF | Удаление сеанса |
| PATCH /users/me | Вход + CSRF | Смена language: ru/en |
| GET /users?page=1 | Администратор | По 50 пользователей, открытые поля и роли |
| GET /users/:id | Администратор или собственный ID | Профиль без хеша пароля |
| POST /users | Администратор + CSRF | Приглашение студента: email, firstName, lastName, phone, language |
| GET /courses | Вход | До 100 активных курсов. Администратор может передать `includeArchived=true` |
| POST /courses | Администратор + CSRF | title и необязательное description |
| PATCH /courses/:id | Администратор + CSRF | Изменение title или description, архивирование через `state: "archived"` |
| GET /groups/:id/roster.csv | Администратор или преподаватель группы | CSV состава группы с периодами обучения. Выгрузка журналируется |
| GET /students/:id/card | Администратор или преподаватель группы | Профиль, доступные зачисления и сводка посещаемости. Служебная заметка доступна администратору |
| PATCH /students/:id/note | Администратор + CSRF | Сохранение служебной заметки с проверкой версии |
| GET /materials, GET /materials/:id | Вход | Доступные материалы и версии PDF по правам группы |
| POST /materials, PATCH /materials/:id | Администратор или преподаватель группы + CSRF | Черновик, редактирование, публикация и архив |
| POST /materials/:id/files | Администратор или преподаватель группы + CSRF | PDF до 10 МиБ, имя в `X-Filename` и версия записи в `version` |
| GET /materials/:id/files/:fileId | Вход | Скачивание PDF с проверкой актуального доступа |
| GET /notifications, PATCH /notifications/:id | Владелец уведомления | Список уведомлений и отметка прочтения |
| GET /lessons/:id/attendance | Администратор или преподаватель занятия | Состав, отметки, версия и доступность редактирования |
| PUT /lessons/:id/attendance | Администратор или преподаватель занятия + CSRF | Сохранение отметок с проверкой версии. `complete: true` проводит занятие после окончания |
| GET /groups | Вход | До 100 доступных пользователю групп |
| GET /groups/:id | Доступ к группе | Группа и преподаватели; сотрудники получают состав, студент — своё зачисление |
| POST /groups | Администратор + CSRF | courseId, code, title, startDate, endDate, capacity, teacherIds, state |
| POST /groups/:id/enrollments | Администратор + CSRF | studentId, startDate; одно зачисление без дубликатов |
| GET /lessons?weekOf=YYYY-MM-DD | Вход | weekStart, weekEnd, weekDays, timeZone и доступные занятия |
| POST /lessons | Администратор + CSRF | groupId, teacherId, title, startsAt, endsAt, format, location |

## Точные правила

- Изменяющие запросы отправляются с Origin, совпадающим с APP_ORIGIN, и заголовком X-CSRF-Token из /auth/csrf. Cookie отправляется браузером автоматически.
- После успешного входа нужно использовать новый csrfToken из ответа.
- Даты обучения: YYYY-MM-DD; моменты занятий: ISO 8601 со смещением Израиля на эту дату, например 2026-11-20T18:00:00+02:00. Смещение проверяется сервером. Неделя определяется по календарной дате Израиля, вс–сб.
- Для онлайн-занятия location начинается с https://; для очного содержит адрес/аудиторию. Преподаватель должен быть назначен выбранной группе.
- Значение localInvitationToken возвращается только когда LOCAL_INVITES=true. Это учебная замена доставки почты, а не публичный механизм production. В журналах код не сохраняется.
- Телефон вводится с + и кодом страны; сервер проверяет и нормализует международный номер. Проверка формата не подтверждает владение номером.
- В ответах нет password_hash, session token_hash и токенов других аккаунтов.
- Ошибка имеет code, messageKey, fieldErrors и requestId. Используются 401, 403, 404, 409, 422 и 429. Запрет доступа к конкретному чужому объекту возвращает 404.

Машиночитаемое описание — openapi.json. Поля, отсутствующие в схеме создаваемого объекта, отклоняются. Повторное зачисление закрытого студента и восстановление периодов будут реализованы отдельно; сейчас повторная пара студент–группа возвращает 409.
