# Результат первого этапа

Дата: 19 ноября 2026 года. Версия: 0.2.0. Основа: ТЗ 1.3.

## Реализовано

- Миграция MySQL с внешними ключами, уникальными ограничениями и историей применения.
- Express API с Argon2id, сеансами MySQL, HttpOnly cookie, CSRF, проверкой Origin и ограничением попыток входа.
- Раздельные аккаунты и серверные права администратора, преподавателя и студента.
- Курсы, группы, назначение преподавателя при создании группы.
- Одноразовое приглашение студента и принятие с установкой пароля. В учебной сборке код выдаётся администратору локально, почтовой доставки нет.
- Зачисление с проверкой вместимости, уникальности и начального периода обучения.
- Расписание с неделей вс–сб, UTC-хранением времени и проверкой смещения Израиля.
- Защита от пересечений занятий и конкурентного занятия последнего места.
- RU/EN с немедленным применением и сохранением в профиле.
- Журнал событий, инструкции, OpenAPI и Docker Compose.

## Подтверждённые проверки

Серверные интеграционные проверки выполнены на MySQL Community Server 8.4.7, не на SQLite и не на имитации базы. Сборка React успешно завершена. После выделения сервисного слоя интеграционный прогон выполнен повторно.

| Сценарий | Результат |
| --- | --- |
| Доступ без входа; CSRF и посторонний Origin | Пройден |
| Вход, отдельные аккаунты, cookie и хеш идентификатора сеанса | Пройден |
| Чужие группы и профили, запрет административных действий преподавателю | Пройден |
| Неделя Израиля, вс–сб, границы года и переходы часов | Пройден |
| Создание студента, нормализация телефона, одноразовое приглашение | Пройден |
| Параллельное зачисление на одно место | Пройден: одно 201 и одно 409, одна запись |
| Параллельное создание пересекающихся занятий одного преподавателя | Пройден: одно 201 и одно 409, одна запись |
| Неверные даты и смещения времени | Пройден |
| Сохранение языка и отзыв сеанса заблокированного аккаунта | Пройден |
| Выход и отсутствие паролей в журнале | Пройден |

Итог Node test runner: 11 успешных проверок с учётом родительского сценария, 0 ошибок. Браузером проверены загрузка приложения и внешний вид страницы входа. Полный проход кабинетов выполнен на уровне HTTP API; визуальная приёмка всех форм за авторизацией ещё требуется.

Docker Compose проверен как конфигурация и включён в комплект. В текущем окружении нет Docker Engine, поэтому сборка образов и запуск именно контейнерного комплекта здесь не выполнялись. Работоспособность серверного кода и миграций проверена отдельным запуском MySQL и Node.js.

## Границы результата

Это законченный первый срез приложения, но не готовая CRM для реальных студентов. Весь перечень A01–A59 не заявлен как выполненный. 2FA, почтовые процессы, полноценные жизненные циклы, посещаемость, материалы и файлы, задания, финансы и рабочее размещение остаются впереди. Настройка APP_ENV=production заблокирована, чтобы учебную сборку нельзя было случайно принять за готовую рабочую систему.

Следующий этап — жизненный цикл зачислений и групп, изменение расписания и посещаемость; затем материалы и домашние задания.
